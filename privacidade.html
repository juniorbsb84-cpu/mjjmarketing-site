Privacy Policy

Last updated: August 14, 2026

This Privacy Policy applies to the internal software tool and operational workflows operated by MJJ Marketing ("the tool"), accessible at https://mjjmarketing.com.br. The application is an internal, private system utilized exclusively by its owner to manage a single Google Ads account.

1. Data Accessed via Google APIs

Our internal application connects to Google Ads API endpoints strictly under OAuth 2.0 authorization. The data accessed is restricted to:

  • Campaign configuration identifiers, status codes, and structural parameters.
  • Aggregated performance metrics: impressions, clicks, cost/spend, and conversion counts.
  • Keyword performance ideas and search volume estimates from Google's Keyword Planner.

2. Data Usage and Limitation of Scope

Data retrieved from Google APIs is processed exclusively on local runtime environments for internal performance monitoring, loss prevention rules, and reporting. The tool does not provide multi-tenant access, does not collect personal data from website visitors, and does not sell or distribute Google Ads data to any external parties.

3. Third-Party Sharing and LLM Disclosures

No Google Ads account data, performance metrics, or campaign structures are transferred or transmitted to third parties.

A third-party large language model is used internally for one purpose only: drafting marketing copy (ad headlines, descriptions, and landing page text) from public product listing information. The data sent to that provider is limited to a product category, a public product name and description, and text from publicly accessible sales pages. It never receives Google account credentials, OAuth tokens, campaign identifiers, or any metric obtained from the Google Ads API. The decision logic that can pause a campaign is deterministic and runs entirely on the operator's machine, with no external model involved.

4. Data Storage and Security

All OAuth tokens and API access credentials are stored in a local environment file on the operator's own machine, excluded from version control and restricted to the operating system account that runs the tool. No cloud-based public databases or external servers store sensitive token data, and credentials are never transmitted to any third party.

5. Data Retention and Deletion

Performance data retrieved from the Google Ads API is retained locally only for as long as it is needed for campaign monitoring and reporting, and is deleted when no longer required. OAuth tokens are revoked and deleted immediately upon request or when the integration is discontinued. Access can be revoked at any time by the account owner through the Google Account permissions page.

6. Limited Use Disclosure

The use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through the Google Ads API is used solely to provide and improve the internal functionality described above, is not used for advertising purposes beyond the owner's own account, is not sold or transferred, and is not used to build profiles or train generalized artificial intelligence models.

7. Website Visitors

This website is composed entirely of static pages. It sets no cookies, loads no analytics or advertising scripts, embeds no third-party fonts, trackers, or external resources, and contains no forms. No personal data of any kind is collected, stored, or processed from visitors to this site. Visiting these pages does not create a data record.
